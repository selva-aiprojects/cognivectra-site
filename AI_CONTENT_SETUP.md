# 🤖 CogniVectra AI Content Automation - Complete Setup Guide

## Overview

This system automatically generates high-quality, AI-powered blog posts tailored to CogniVectra's expertise in cloud automation, DevOps, and SaaS scaling. Posts are:

1. **Generated** using OpenAI GPT-4
2. **Saved** to Supabase as drafts
3. **Reviewed** by administrators
4. **Published** to blog and social media platforms

---

## Quick Start

### 1. Install Dependencies

```bash
npm install axios node-cron
```

### 2. Set Up Environment Variables

Create `.env` file in project root:

```env
# Core
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-anon-key
OPENAI_API_KEY=sk-your-key-here

# Social Media (Optional - set if you want auto-posting)
LINKEDIN_ACCESS_TOKEN=your-linkedin-token
INSTAGRAM_ACCESS_TOKEN=your-ig-token
INSTAGRAM_BUSINESS_ACCOUNT_ID=your-ig-account-id
FACEBOOK_ACCESS_TOKEN=your-fb-token
FACEBOOK_PAGE_ID=your-fb-page-id
DEFAULT_POST_IMAGE_URL=https://your-domain.com/image.png
```

### 3. Update Database Schema

Copy and run in Supabase SQL Editor:

```sql
-- Update posts table
ALTER TABLE public.posts ADD COLUMN IF NOT EXISTS status TEXT DEFAULT 'draft';
ALTER TABLE public.posts ADD COLUMN IF NOT EXISTS review_requested_at TIMESTAMP WITH TIME ZONE;
ALTER TABLE public.posts ADD COLUMN IF NOT EXISTS published_platforms TEXT[] DEFAULT ARRAY[]::TEXT[];
ALTER TABLE public.posts ADD COLUMN IF NOT EXISTS tags TEXT[] DEFAULT ARRAY[]::TEXT[];
ALTER TABLE public.posts ADD COLUMN IF NOT EXISTS social_media_data JSONB;

-- Create social media tracking table
CREATE TABLE IF NOT EXISTS public.social_media_posts (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  post_id BIGINT NOT NULL REFERENCES public.posts(id) ON DELETE CASCADE,
  platform TEXT NOT NULL CHECK (platform IN ('linkedin', 'instagram', 'facebook')),
  platform_post_id TEXT,
  published_at TIMESTAMP WITH TIME ZONE,
  engagement_data JSONB,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::TEXT, NOW()),
  UNIQUE(post_id, platform)
);

CREATE INDEX idx_social_media_posts_platform ON public.social_media_posts(platform);
```

### 4. Generate Your First Post

```bash
npm run generate-post:enhanced
```

This will:
- Generate a unique AI post about CogniVectra's expertise
- Create title, excerpt, body, and social media versions
- Save to Supabase in "pending_review" status
- Display admin notification with next steps

### 5. Review & Approve in Admin Dashboard

1. Go to `http://localhost:5173/admin`
2. Click "Pending Review" tab
3. Review the AI-generated content
4. Click "✅ Approve" to publish to blog
5. Post auto-publishes to LinkedIn, Instagram, Facebook (if configured)

## Social Media Integration

### LinkedIn

**Setup:**
1. Go to https://www.linkedin.com/developers/apps
2. Create app → Add "Ugc Posts" product
3. Get Access Token (60-day expiry)
4. Add to `.env`: `LINKEDIN_ACCESS_TOKEN`

**Post Limit:** 10 posts/month (free tier)

### Instagram

**Setup:**
1. Go to https://developers.facebook.com
2. Create Business App
3. Add Instagram Basic Display product
4. Get Business Account ID and Access Token
5. Add to `.env`:
   ```env
   INSTAGRAM_ACCESS_TOKEN=...
   INSTAGRAM_BUSINESS_ACCOUNT_ID=...
   ```

**Requirements:**
- Business Instagram account (not personal)
- Need to upload images separately

### Facebook

**Setup:**
1. Go to https://developers.facebook.com
2. Create Business App
3. Add Graph API product
4. Get Page ID and Page Access Token
5. Add to `.env`:
   ```env
   FACEBOOK_ACCESS_TOKEN=...
   FACEBOOK_PAGE_ID=...
   ```

## Monitoring & Analytics

### View Published Posts

**In Supabase:**
- `posts` table: All post content and status
- `social_media_posts` table: Which platforms each post was published to

**In Admin Dashboard:**
- Filter by status, date, tags
- View publication history
- See social media metrics (when integrated)

### Engagement Tracking

The system stores:
- Post IDs from each platform
- Publication timestamps
- Engagement metrics (likes, shares, comments)

To retrieve metrics:

```sql
SELECT 
  p.title,
  smp.platform,
  smp.published_at,
  smp.engagement_data
FROM posts p
LEFT JOIN social_media_posts smp ON p.id = smp.post_id
WHERE p.status = 'published'
ORDER BY smp.published_at DESC;
```

## Troubleshooting

### "Missing environment variables"
- Check `.env` file exists in project root
- Verify all required variables are set
- Restart dev server: `npm run dev`

### "OpenAI API error"
- Verify `OPENAI_API_KEY` is correct
- Check account has credits
- Review rate limits

### "Supabase connection error"
- Verify `VITE_SUPABASE_URL` and key are correct
- Check Supabase project is active
- Test connection: 
  ```bash
  npm run dev
  ```

### "Social media posting fails"
- Tokens expire after 60 days - regenerate
- Check API limits (LinkedIn: 10/month free)
- Verify account IDs are correct

### "Posts not appearing in admin"
- Wait 30 seconds for Supabase sync
- Refresh page (F5)
- Check browser console for errors (F12)
