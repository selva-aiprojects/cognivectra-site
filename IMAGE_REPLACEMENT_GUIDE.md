## Image Optimization Best Practices

### Before Uploading:
1. **Resize appropriately:**
   - Hero images: 3840×2160 (4K) minimum, 7680×4320 (8K) ideal
   - Icons: 512×512 or 1024×1024
   - Thumbnails: 800×450

2. **Optimize file size:**
   - Use WebP format for best compression (70-80% smaller than PNG)
   - Use TinyPNG or ImageOptim to compress without quality loss
   - Target: 2-5 MB for hero images, <500KB for icons

3. **Color profile:**
   - Use sRGB color space for web
   - Ensure colors match your brand palette

4. **File naming:**
   - Use descriptive names: `home-hero-automation-8k.webp`
   - Keep lowercase with hyphens
   - Include resolution indicator

## Performance Considerations

### Lazy Loading
Consider adding lazy loading for images below the fold:
```jsx
<img
  src="/hero_image.webp"
  alt="Description"
  loading="lazy"
  className="hero-image-modern"
/>
```

### Responsive Images
Use srcset for different screen sizes:
```jsx
<img
  src="/hero_image_4k.webp"
  srcset="/hero_image_1080p.webp 1920w,
          /hero_image_4k.webp 3840w,
          /hero_image_8k.webp 7680w"
  sizes="(max-width: 768px) 100vw, 50vw"
  alt="Description"
  className="hero-image-modern"
/>
```
