# CogniVectra Website

A premium B2B SaaS marketing website and business management platform for automated enterprise operations.

## 🚀 Quick Start

1. `npm install`
2. `npm run dev`

## 📚 Documentation

- [🧠 **AI & CrewAI State Management**](./docs/technical/AI_CREWAI_STATE_MANAGEMENT.md): Technical reference for LangGraph orchestration and cyclic reference handling.
- [🛡️ **AI Safety Guardrails**](./docs/technical/AI_SAFETY_GUARDRAILS.md): Documentation on toxicity filtering, injection defense, and token optimization.
